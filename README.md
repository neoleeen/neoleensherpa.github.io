# Personal Portfolio Website

A responsive personal portfolio website showcasing my skills, projects, experience and certifications as a developer. Built from scratch with HTML, CSS and JavaScript as part of my Software Development Internship with London Success Academy.

**Live site:** [Add link in Step 7](https://example.com)

## Features

- Responsive layout for desktop, tablet and mobile
- Light and dark mode switch, remembered between visits
- Sticky navigation bar with smooth scrolling
- Mobile dropdown menu
- Sections that fade in and out while scrolling
- Downloadable CV and viewable certificates

## Built With

- **HTML5**: semantic page structure
- **CSS3**: Flexbox, Grid, CSS variables and media queries
- **JavaScript**: theme switching, mobile menu and scroll effects

## Project Structure

```
portfolio-website/
├── index.html      # Page content and structure
├── style.css       # Styling, layout and responsive design
├── script.js       # Interactive features
├── files/          # CV and certificates (PDF)
├── images/         # Images
└── README.md       # Project description
```

## Run It Locally

1. Clone or download this repository
2. Open the folder in VS Code
3. Right-click `index.html` and choose **Open with Live Server**
   (or just double-click `index.html` to open it in a browser)
